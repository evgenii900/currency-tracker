
# 💱 Currency Tracker

Автоматический трекер курса валют. Раз в неделю сохраняет актуальный курс USD/RUB в формате JSON.

## 📦 Что внутри

- `rates.json` — файл с актуальным курсом (обновляется автоматически)
- `.github/workflows/update-currency.yml` — скрипт для автоматического обновления

## 🚀 Как это работает

Каждое воскресенье в 6:00 UTC GitHub Actions:
1. Запрашивает актуальный курс доллара к рублю через бесплатное API
2. Сохраняет результат в `rates.json`
3. Автоматически создает коммит с обновленными данными

## 📊 Пример данных

```json
{
  "base": "USD",
  "date": "2026-08-23",
  "rates": {
    "RUB": 91.52
  }
}
```

## 🔧 Ручной запуск

Если хочешь обновить курс вне расписания:
1. Зайди во вкладку **Actions**
2. Выбери **Update Currency Rates**
3. Нажми **Run workflow**
