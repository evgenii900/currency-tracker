# 💱 Currency Tracker

Автоматический трекер курса валют. Раз в неделю сохраняет актуальный курс USD/RUB в формате JSON.

## 📦 Что внутри

- `rates.json` — файл с актуальным курсом (обновляется автоматически)
- `.github/workflows/update-currency.yml` — скрипт для автоматического обновления

## 🚀 Как это работает

Каждое воскресенье в 6:00 UTC GitHub Actions:
1. Запрашивает актуальный курс доллара к рублю через бесплатное API
2. Сохраняет результат в `rates.json`
3. Автоматически создает коммит с обновленными данными

## 📊 Пример данных

```json
{
  "base": "USD",
  "date": "2026-08-23",
  "rates": {
    "RUB": 91.52
  }
}

Файл для автозапуска (cron-скрипт)
Создай файл .github/workflows/update-currency.yml. Вот готовый код, который раз в неделю (например, каждое воскресенье в 6 утра по UTC) будет ходить за курсом доллара к рублю и сохранять его:

yaml
name: Update Currency Rates

on:
  schedule:
    # Каждое воскресенье в 6:00 UTC
    - cron: '0 6 * * 0'
  workflow_dispatch:  # чтобы можно было запустить вручную с телефона

jobs:
  update-rates:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4

      - name: Fetch USD to RUB rate
        run: |
          # Простой запрос к бесплатному API (без ключа)
          curl -s "https://api.exchangerate-api.com/v4/latest/USD" > rates.json

      - name: Commit and push
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add rates.json
          git commit -m "🔄 Обновление курса валют: $(date '+%Y-%m-%d')" || exit 0
          git push
Что делает: раз в неделю скачивает актуальный курс валют в файл rates.json и автоматически делает коммит. Активность есть, но выглядит как нормальная работа с данными.
